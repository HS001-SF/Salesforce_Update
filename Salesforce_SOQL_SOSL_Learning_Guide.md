# Salesforce SOQL & SOSL Learning Guide (Beginner to Advanced)

## Objective
Learn Salesforce SOQL and SOSL using real-world scenarios from beginner to advanced.

## Roadmap
### Level 1 - Basic SOQL
- SELECT
- WHERE
- ORDER BY
- LIMIT
- Filtering

Scenarios:
- Retrieve Accounts
- Retrieve Users
- Filter by Industry
- Sort by Revenue
- Top N Records

### Level 2 - Intermediate
- Date Literals
- LIKE
- Comparison Operators

Scenarios:
- Created Today
- Last Month
- Starts With
- Contains
- Revenue Filters

### Level 3 - Relationship Queries
- Child-to-Parent
- Parent-to-Child

Scenarios:
- Contact with Account
- Opportunity with Account
- Account with Contacts
- Account with Opportunities

### Level 4 - Aggregate Queries
- COUNT
- SUM
- AVG
- MIN
- MAX
- GROUP BY
- HAVING

### Level 5 - Advanced SOQL
- Dynamic SOQL
- FOR UPDATE
- ALL ROWS
- Semi-Join
- Anti-Join

### Level 6 - Salesforce Field Service
Objects:
- WorkOrder
- ServiceAppointment
- AssignedResource
- ServiceTerritory
- ServiceTerritoryMember

### Level 7 - SOSL
- Global Search
- Multi-object Search
- Wildcard Search

## Best Practices
- Avoid SOQL in loops.
- Query only required fields.
- Use relationship queries.
- Use aggregate functions.
- Use bind variables.
- Respect governor limits.

## Interview Focus
- Relationship Queries
- Aggregate Queries
- Dynamic SOQL
- Query Optimization
- Governor Limits
- SOSL vs SOQL
- Field Service Queries

## Outcome
- Write optimized SOQL.
- Build efficient Apex.
- Solve real-world scenarios.
- Prepare for Salesforce Developer interviews.
