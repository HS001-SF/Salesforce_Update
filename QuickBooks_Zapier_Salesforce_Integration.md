# Salesforce QuickBooks Integration using Zapier

## Objective
Integrate Salesforce with QuickBooks Online using Zapier to automate customer, invoice, and payment synchronization.

## Business Requirement
- Create QuickBooks customers from Salesforce Accounts.
- Create invoices from Closed Won Opportunities.
- Update Salesforce when invoices are paid.

## Architecture
Salesforce -> Zapier -> QuickBooks Online

## Prerequisites
- Salesforce Org
- QuickBooks Online
- Zapier Account
- API Access

## Configuration Steps
1. Connect Salesforce.
2. Connect QuickBooks.
3. Create Zap.
4. Configure Trigger.
5. Configure Action.
6. Map Fields.
7. Test.
8. Publish.

## Common Use Cases
- New Account -> Create Customer
- Closed Won Opportunity -> Create Invoice
- Invoice Paid -> Update Salesforce

## Benefits
- No-code automation
- Automatic synchronization
- Reduced manual work
- Improved data accuracy

## Best Practices
- Test in Sandbox.
- Use unique identifiers.
- Monitor Zap history.
- Configure error notifications.
